# Rust 学习路径

以下是所有推荐项目按**入门 → 进阶 → 高级**三个阶段的系统学习路线，每个阶段标注了核心 Rust 概念和前置要求。其中类型标注带 **·AI** 的项目为与人工智能相关的实践项目（调用大模型 API、构建 AI 应用等），按各阶段的 Rust 知识点与难度穿插安排，难度随学习进度递进；每个 AI 项目下方的「AI 项目说明」给出其被安排在该阶段的理由：

---

## 🌱 入门阶段：掌握 Rust 基础

**目标**：熟悉所有权、借用、生命周期、模式匹配、错误处理、基础集合

| 序号 | 项目 | 类型 | 核心学习内容 | 预计时间 |
|:---:|------|------|-------------|:-------:|
| 1 | **命令行待办事项应用** | 系统/CLI | 结构体、枚举、`Option`/`Result`、文件 I/O、JSON 序列化 | 3-5天 |
| 2 | **类 grep 的命令行搜索工具** | 系统/CLI | 字符串处理、正则表达式、迭代器、命令行参数解析 | 3-4天 |
| 3 | **Markdown 解析器** | 系统/CLI | 递归下降解析、字符串切片、模式匹配、枚举状态机 | 5-7天 |
| 4 | **JSON 解析器** | 系统/CLI | 递归数据结构、泛型、错误链、测试驱动开发 | 5-7天 |
| 5 | **命令行 AI 对话客户端（调用大模型 API）** | 系统/CLI·AI | 结构体/枚举建模消息与角色、`serde_json` 请求响应序列化、`Result` 错误处理（网络/鉴权/限流）、环境变量管理密钥、多轮对话历史与文件 I/O、`clap` 参数解析 | 3-5天 |
| 6 | **终端贪吃蛇游戏** | 游戏 | `crossterm` 终端控制、游戏循环、状态管理、输入处理 | 5-7天 |

> **AI 项目说明（#5 命令行 AI 对话客户端）**：排在 JSON 解析器之后。调用大模型 API 的本质就是「构造 JSON 请求 → 解析 JSON 响应 → 处理错误」的循环，正好复用 #1 的文件 I/O 与 #4 的序列化知识；用阻塞式 HTTP 客户端（如 `ureq`）即可完成，不引入异步复杂度。以角色/消息建模练结构体与枚举，以网络/鉴权/限流错误练 `Result`，是入门阶段最自然的 AI 落点。

**入门阶段完成标准**：能独立编写 500 行以内的 Rust 程序，熟练使用 `cargo`，理解编译器错误信息；能通过 HTTP 调用大模型 API 完成一次完整的多轮对话。

## 🚀 进阶阶段：深入核心特性

**目标**：掌握泛型、Trait、智能指针、并发基础、异步编程、生命周期进阶

### 2.1 数据结构与内存管理（必选）

| 序号 | 项目 | 类型 | 核心学习内容 | 预计时间 |
|:---:|------|------|-------------|:-------:|
| 7 | **链表实现** | 数据结构 | `Box`/`Rc`/`RefCell`、递归、自引用结构、Drop trait | 5-7天 |
| 8 | **动态数组（Vec）从零实现** | 数据结构 | 裸指针（`unsafe`）、内存分配、扩容策略、泛型 | 7-10天 |
| 9 | **哈希表从零实现** | 数据结构 | 哈希算法、冲突处理、动态重哈希、迭代器模式 | 7-10天 |
| 10 | **LRU 缓存** | 数据结构 | `HashMap` + 双向链表组合、生命周期管理、缓存淘汰策略 | 5-7天 |
| 11 | **内存向量检索库（相似度搜索 + Top-K）** | 数据结构·AI | `Vec`/`HashMap` 组合、泛型与 Trait 抽象、余弦/欧氏相似度、Top-K 排序与堆、迭代器适配、批量插入与查询 | 5-7天 |

> **AI 项目说明（#11 内存向量检索库）**：排在数据结构小节末尾（LRU 之后）。向量检索是 `HashMap` + `Vec` 的组合应用，相似度计算与 Top-K 排序练泛型、Trait 抽象和堆操作；它是后续 RAG 的「检索引擎内核」，先以纯内存、无网络的形式把数据结构打牢。

| 序号 | 项目 | 类型 | 核心学习内容 | 预计时间 |
|:---:|------|------|-------------|:-------:|
| 12 | **线程池实现** | 并发 | `std::thread`、通道（`mpsc`）、`Arc`/`Mutex`、任务队列 | 5-7天 |
| 13 | **生产者-消费者队列** | 并发 | 条件变量、有界队列、多线程同步、死锁避免 | 5-7天 |

| 15 | **TCP 聊天服务器** | 网络/异步 | 多客户端管理、广播消息、异步 I/O、状态共享 | 5-7天 |
| 16 | **异步大模型并发调用器（流式输出 + 限流）** | 并发·AI | `tokio` 异步运行时、`reqwest` 异步 HTTP、`async/await` 与 `Future`、SSE 流式响应解析、`Semaphore` 并发限流、`mpsc` 通道汇聚结果、超时与重试 | 7-10天 |

> **AI 项目说明（#16 异步大模型并发调用器）**：排在并发与异步小节末尾。该项目几乎覆盖本小节全部考点——`tokio` + `reqwest` + `async/await` + SSE 流式解析 + `Semaphore` 限流 + `mpsc` 结果汇聚，并直接衔接 #14 HTTP 服务器、#15 TCP 聊天服务器的异步基础，是进阶阶段 AI 线的核心。

> **AI 项目说明（#19 WASM 浏览器端 AI 聊天界面）**：属可选的前端/WASM 分支。以 `wasm-bindgen` + JS 互操作 + `ReadableStream` 流式读取，把上一项的流式能力搬到浏览器；难度与 Yew 单页应用相当，供走前端路线的学习者选用。

> **AI 项目说明（#22 AI 代码审查命令行工具）**：属可选的系统工具分支。以标准输入/输出、管道、目录遍历、退出码为主，AI 只作为「被调用的外部能力」，正好用上本小节的进程与管道知识，同时练结构化输出解析。

**进阶阶段完成标准**：能处理复杂生命周期，编写线程安全代码，理解 `async/await` 底层机制；能并发调用大模型 API 并正确处理流式响应。

### 3.7 综合目标项目：RustFS 分布式对象存储

> **定位**：不是从零实现 RustFS，而是把 [RustFS](https://github.com/rustfs/rustfs) 作为生产级基础设施，围绕它开发个人产品、周边工具，并选择性阅读源码。
>
> **分类**：系统编程 / 基础设施 / 分布式存储  
> **推荐位置**：高级阶段最终 Capstone 项目  
> **前置要求**：完成进阶阶段 2.2 并发与异步，以及高级阶段 3.1 中的异步任务调度器、WebSocket 聊天服务器；熟悉 Docker、S3 API 基础概念。

| 序号 | 项目 | 类型 | 核心学习内容 | 预计时间 |
|:---:|------|------|-------------|:-------:|
| 45 | **RustFS 目标项目：个人 S3 兼容对象存储 / 私有云盘** | 系统 / 基础设施 / 分布式存储 | Tokio 异步运行时、S3 API、纠删码、分布式存储架构、Docker 部署、Rust 大型项目组织、性能调优、存储引擎分层设计 | 21-30天 |
| 46 | **本地 RAG 知识库应用（RustFS + 向量检索 + LLM）** | 系统 / 基础设施·AI | 文档解析与分块、嵌入向量生成与存储、检索增强生成（RAG）管线、RustFS/S3 存储集成、异步编排、前端或 CLI 交互 | 14-21天 |

> **AI 项目说明（#46 本地 RAG 知识库）**：作为 Capstone 的 AI 扩展。它把前面的成果全部串起来——RustFS 做存储（#45）、向量检索（#11/#33）做召回、大模型做生成，是难度最高、最贴近真实产品的综合项目，因此放在路线终点。

#### 项目目标

- 能本地部署单机版 RustFS
- 能通过 S3 SDK 上传、下载、列出、删除对象
- 能开发一个个人可用的产品原型：
  - 🎨 **前端相关**：React/Vue + S3 SDK 的个人网盘
  - 🎨 **前端相关**：Tauri 桌面文件同步/备份客户端
  - **CLI 工具**：Rust 编写的批量文件同步工具
- 能理解 RustFS 的核心架构：
  - Pool → Sets → SetDisks → LocalDisk 分层
  - ECStore 存储引擎
  - 纠删码、元数据管理、S3 网关、网络层
- 可选：在 RustFS 之上构建本地 RAG 知识库，对存储的文档做检索增强问答
- 可选：向 RustFS 提交 Issue、文档改进或小型 PR
