# 使用Lathe工具学习Rust

> 把 Lathe 提炼成无 CLI 的 Agent Skill（**持续迭代中**），用它生成并管理 Rust 动手实践课程。

一个使用 [Lathe](https://github.com/devenjarvis/lathe) 来学习Rust的个人仓库记录。本仓库包含：

- 将 Lathe 提炼成无 cli 版本的 **skills**（持续迭代中）
- skills 的 [使用说明文档](./docs/skills-tutorial.md)
- 通过 kimi 网页版规划的 [Rust 学习路线](./docs/learn-rust-way.md)
- 通过该 skills 生成的对应课程（`tutorials/`）
- 相关学习代码的记录（`code/`，submodule）

本仓库中的 skills **初版**通过 Qwen 3.7max 读取 Lathe 中的代码改写生成，后续持续迭代优化：已重构为统一的模块化目录（`skills/lathe/`），支持中英文双语触发、多种内置写作语气与风格标杆体系、教程验证时的版本冲突检测与修复、多路径教程存储与 metadata 自愈重建、散落教程的扫描登记、技能版本标记、重要概念从已知知识引申的概念锚定、学习目标管理与课程收尾完结/复习工作流等能力。

**v0.5.3 新增**：**面试文档**（`/lathe 面试 <slug>`——按 Part 分章的面试要点文档，支持从生成/复习/续写三条路径产出，续写时自动同步，并带遗漏检测与补写确认）；同时做了**一轮生成提速与加载精简**（研究分级触发、预检/自检去重、配额前置、加载集 47.6 KB → 41.5 KB）。

**v0.5.3.1 优化**：**配额矩阵 + 主题新颖度分级**——新增 `topic_novelty`、`course_plan`、`continuity.open_threads`；检索预算、地基章节、标注、概念锚定按「全新 / 相邻 / 熟悉」三档自适应；continuity 扩到 1200 字软上限 / 2000 字硬上限，减少长课程重读与漂移；练习、代码块、图表与自检规则同步调整为"教学脚手架优先，装饰性旁白收紧"。

**v0.5.4 优化**：**讲透优先 + 验证/续写补强**——配额只约束知识点数量，不再限制解释长度、类比句数、标注总数或代码行数；代码块区分 `runnable` / `fragment` / `exercise` / `text` / `output` / `expected_failure`，验证只执行可执行块和检查点；交付前自检改为六项讲透 + 代码完整性 + 知识点数量。新增 `changed_interfaces`、`open_threads` 归档、未验证横幅、续写契约与 `course_plan` 漂移检查、旧签名自查、级联失效和 `_needs_backfill`。单部分正文/单块过大时优先拆分，不压缩解释。旧教程无需强制迁移；未标记代码块仍按 `runnable` 处理，旧教程中的片段/`...` 若被验证误判，补 `fragment` 标记即可。

**v0.6.0 优化**（原 0.5.5 分支并入，0.5.5 不单独发布）：**目标是你列出的知识点一条都不能悄悄消失**。主线七项：
**① 知识点账本 `syllabus.json`** — 每个承诺的知识点一行一条、六种状态（`planned` / `queued` / `taught` / `self-study` / `dropped_by_user` / `duplicate`）只改不删；`metadata.syllabus_ids` 做 ID 镜像（整条被删时能点名缺哪条），`knowledge_backlog` 是 `queued` 的投影。
**② 写前计划确认 + 覆盖回执** — 列了知识点、或有顺延/去重/闸门时先给计划请你确认；交付时附「知识点 → 章节」回执与对账等式，数字直接粘贴检查脚本输出。
**③ 练习承接三档 + 积压治理** — 练习不再限制「能否引入新概念」，每道题按档 1 融入 / 档 2 承接章 / 档 3 顺延分流（档 1 须有「疑问复述 + 解释 + 可运行验证」三件套）；用户清单先归一化再按名额分配表分批，积压上限 14 条，触闸门默认扩 Part 而不是降级；被延后的知识点必须在正文留提醒，且档 1 承诺有 `promised_by` 可查询——上一部分答应「以后会讲」的条目如果那个部分写完还没讲，`ledger_check.py` 直接报 `已承诺未兑现`。
**④ 交付前试跑 + 技能自带检查脚本** — `scripts/` 下 `part_lint.py`（含复习材料专用档位）、`trial_run.py`、`ledger_check.py`（`--receipt` / `--finish` / `--continuity` / `--legacy`），纯标准库 Python 3；只检查本次新写的部分。
**⑤ 规则收拢** — 账本、来源与名额、去重、闸门、写前确认、回执、练习承接集中到 `references/knowledge-ledger.md` 单一事实源。
**⑥ 提问勘误需要你手动确认** — 回复「好」「嗯」不算；确认后会扫出**影响面**并同步复习材料 / 面试文档里的同一处摘录、刷新账本 `at`、复跑账本检查（改小节标题不再让账本自检失败）。
**⑦ 按「讲透优先」取消篇幅上限** — 正文约 10,000 中文字符、单个 `runnable` 约 100–120 行只是参考观察值；是否拆部分只看「独立学习里程碑 / 独立改动面 / 一次能否走完」，不得为控篇幅压缩解释、砍知识点或删运行必需代码。

随后两轮实测继续收紧：**写侧实测**（外部 agent 独立跑生成 + 两次续写）确认 14 条清单零丢失、回执数字与脚本一致；**读取端实测**（列表 / 复习 / 收尾门禁 / 提问）修掉 5 个阻塞级问题——复习再次执行改为顺延编号（旧规则同时要求「顺延」和「停止」）、收尾门禁提到读取正文之前判定、自带脚本对 0.6.0 之前的历史部分自动降级；第三批继续做读侧——**索引预算改成可达的**（旧写法只限每条字数不限条数，3 个部分实测 1969 字、6 个部分必然越界；现在先定各字段条数上限，总量 2200 软 / 3000 硬，`--continuity` 点名该归档哪几条，超出只归档、绝不压缩正文）、**复习改为两段式按需读取**（骨架 + 定点片段，3 个部分实测总读取 243,718 → 约 92 KB，省 62%；兜底是逐块校验摘录是否为原文连续子串，不跑这个检查就不许用两段式）、**`research.md` 归档条目定死写法**（禁止「解决于 part-02（前两条）」这类按位置指代）、`--finish` 在 A 类欠账非空时以 exit 2 表示门禁拒绝、手工编辑检测改看 part 与 `metadata.json` 的 mtime 差（拷贝/克隆不再被误判为「编辑过」而强制全读）、`metadata.json` 新增 **`part_versions`**（逐部分写入版本）、**参数可以直接给教程目录**（沙箱不必 `/lathe 扫描` 登记进用户配置）。旧教程无需迁移：新字段缺失即视为空或自动回落。完整清单见 Releases。

**安装使用：** 从本仓库的 GitHub Releases 页面下载最新版本的技能包（`lathe-x.y.z.zip`），解压后将 `lathe/` 目录复制到 QoderWork 的技能目录即可，详细步骤见 [使用教程](./docs/skills-tutorial.md)。

## Skills 功能一览

所有操作通过 `/lathe` 调用，中英文关键词均可：

| 操作     | 命令                                    | 功能                                                                                                                                            |
| -------- | --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 生成教程 | `/lathe <主题>`                         | 为任意主题生成动手实践型教程的第一部分                                                                                                          |
| 续写教程 | `/lathe 续写\|extend <slug>`            | 为已有教程添加下一部分，可基于本地实际代码进度；新部分含目标达成回顾（该教程已有面试文档时自动同步本部分）                                      |
| 收尾完结 | `/lathe 续写 收尾 <slug>`               | 生成总结部分（全课程回顾、知识图谱、练习方向）并完结课程；续写可重新开放                                                                        |
| 复习教程 | `/lathe 复习\|review <slug>`            | 生成复习材料：逐部分回顾、自测题、重跑检查点、可继续深入的方向（含 `面试` 关键词时转「面试文档」）                                              |
| 面试文档 | `/lathe 面试\|interview <slug> [part]`  | 生成按 Part 分章的面试要点文档（一句话回答 → 展开 → 追问点 → 我的项目里）；只对教学部分产出，续写时自动同步，中途启用会先检测遗漏再确认补写范围 |
| 验证教程 | `/lathe 验证\|verify <slug>`            | 临时目录中端到端执行教程，含版本冲突检测与修复                                                                                                  |
| 提问内容 | `/lathe 提问\|ask <slug> [part] <问题>` | 基于教程具体内容回答问题；发现教程错误时给出勘误确认块，你手动确认后才修改                                                                        |
| 管理标签 | `/lathe 标签\|tag <slug>`               | 管理教程的搜索标签                                                                                                                              |
| 创建语气 | `/lathe 语气\|voice [名称]`             | 创建自定义写作语气预设                                                                                                                          |
| 扫描登记 | `/lathe 扫描\|scan [目录...]`           | 发现并登记散落各处的已有教程，写入配置以便被 `列表`/`续写`/`验证` 等命令识别                                                                    |
| 列出教程 | `/lathe 列表\|list [slug]`              | 按编程语言分组列出所有教程及各部分状态                                                                                                          |

## 一些经历、牢骚😂

身处 AI 爆发式增长的大环境，就一直都在寻找怎样用AI工具来学习Rust的方法。受限于Anthropic 对国内用户的各种限制，还有使用国外各种优秀大模型需要面临的各种各样的问题。所以把大部分关注点聚焦于可以在国内使用的，好用的，且最好是不用花费太多的AI工具。

国内确实发现一些专门针对学习这个领域的一些探索性的AI相关的产品，比如清华大学的开源项目 [openMAIC](https://open.maic.chat/) ，但是这个项目感觉目前更适合专注于学习某个知识点，这种课堂的模式更适合学生群体。再比如 千问小课堂（当前仅在手机端应用找到入口，网页端以及桌面应用端都找不到😂），也是类似讲课的模式，更适合学生群体。

很早也关注过Google的实验室项目 —— Learn your way。想给它上传Rust官网那套教程文档，让它生成学习课程，可是就是一直让我填一个表格，无法进入使用😩。后来偶然发现了 网页版 Gemini 的学习模式，一下子打开新世界。采用问答的形式，及时反馈很有成就感，问题讲解的通俗易懂，体验感很好可以当一个在线家教使用。

对于Rust的学习尝试过看官方的学习文档，结果看不下去。通过 Rustlings学习，总是学完现在的前面的又都忘了。花钱买课程，跟看文档一样还是看学不下去。所以一直想找些能通过做项目来学习Rust的方法，问了各种 AI，就是给你列出一些学习项目，就没一个系统性的东西。

直到有天逛 [Zeli](https://zeli.app/zh) 遇到了 [Lathe](https://github.com/devenjarvis/lathe) 这个项目（再次感谢编写这个项目的大佬🙏）， 看了这个工具的介绍惊为天人啊😲！感觉这就是我要找的东西。所以又开始问各种AI，这个工具在国内有啥好的使用媒介。

最开始想法是使用 DeepSeek v4（因为便宜😁）相关的agent工具，看看能不能直接结合 Lathe 这个仓库中的使用教程使用。结果就是感觉有点麻烦，就想着能不能把这个提炼成skills来用，让AI出了一版。再然后就是找有免费额度的国内AI工具，选择了 QoderWork。 有免费额度，能用，操作比较方便，能直接查看生成的教程。找 kimi 总结了些 Rust学习项目，然后这样学起来了😄

目前（2026-10-24）已经很久没有继续学习rust了。9月初的时候失业了，就想着用这个skill来整理和学习一些其他知识，所以这个skill最近一直都在更新，毕竟用多了总会发现一些问题和可优化的点。还是期望能尽快找到工作😤
