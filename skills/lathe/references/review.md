# 复习教程

为久未学习、想先复习再精进的读者生成一份结构化复习材料。复习**不改变课程方向**：不引入新教学内容，不推进"接下来"的线索，只是把已有部分沉淀为可自测的回顾。

**先读共享文件：** 本操作需要 `<SKILL_DIR>/references/writing-core.md` 中的 voice 应用规则；不需要其中的教程结构（复习材料有自己的结构，见下方）。

**触发格式：**
```
/lathe 复习|review <slug>
```

中文关键词 `复习`、`回顾` 与英文 `review`、`revise`、`recap` 等价。

**分支——面试文档模式：** 若参数含**独立的** `面试` / `interview` token，本操作**转为面试文档模式**，改按 `<SKILL_DIR>/references/interview.md` 执行（粒度可选 `part-NN`；文档不存在时会先与你确认存储位置，文档已存在但不完善时会先与你确认补写范围）。**无该 token 时，下方协议完全不变。**

## 协议

0. **解析教程位置与布局。** 按 `<SKILL_DIR>/SKILL.md`“教程位置与双布局”找到该 slug 的课程根目录；正文始终位于根目录。先同时检查两处 metadata，再由位置一次性决定全部辅助文件：

   | 布局 | metadata | canonical ledger | research |
   |---|---|---|---|
   | 0.7.0 新课程 | `_lathe/metadata.json` | `_lathe/knowledge-points.md` | `_lathe/research.md` |
   | legacy 课程 | `metadata.json` | `syllabus.json` | `research.md` |

   两处 metadata 同时存在，或辅助文件跨布局混放，列出冲突路径并停止；不得逐文件回退、拼接、迁移或移动文件。metadata 缺失/损坏时按 `<SKILL_DIR>/references/metadata.md` 的布局线索提出自愈位置，经用户确认重建后再继续。新布局缺 `_lathe/knowledge-points.md` 是错误；legacy 缺 `syllabus.json` 时报告 `知识表：未建立` 并停止生成复习材料，因为无法从 canonical points 计算覆盖情况。不得用 metadata 或 research 的旧点级镜像兜底。

1. **吸收现有教程。** 只读当前布局 metadata，取 `voice`（复习材料沿用同一 voice）、`language`（保持同一正文语言）、`goal`（如有）、`continuity`（控制性示例与固定数字直接取自摘要，无需从正文重新提炼）与 `changed_interfaces`（如有）。读取当前布局 canonical ledger：新布局解析 `_lathe/knowledge-points.md` 固定表，legacy 解析 `syllabus.json`；它是「哪些讲了、讲在哪，哪些还没讲」的唯一权威记录。进度固定按 `taught / (taught + planned + queued)` 计算，未讲清单直接取所有不是 `taught` / `duplicate` 的 canonical points。当前布局 research 存在时，只读取 `## Open Threads Archive` 与 `## Changed Interfaces Archive` 作为方向线索；旧 research 中任何点级、自学或已讲镜像一律忽略，不迁移、不续写。

   然后**按两段式读取正文**（0.6.0 改，见下方成本实测）——复习材料要逐部分回顾并原样摘录，但「回顾」需要的只是骨架，「摘录」需要的只是每部分一段连续原文：

   **第 1 段·骨架（廉价）**，对每个常规部分只取：
   - 全部 `#` / `##` / `###` 标题行；
   - 四个契约行（`**本部分结束时的文件状态：**` 等）；
   - `## 你将构建什么`、`## 检查点`、`## 目标达成回顾`、`## 接下来` 四节的**全文**（自测题与重跑检查点全靠它们）；
   - 其余 `##` 小节的**标题 + 紧随的 3 行**（够写出「这一节构建了什么、核心概念是什么」）。
   一条命令即可：`grep -n -E '^#{1,3} |^\*\*(本部分结束|下一部分起始|本部分不覆盖|练习承接)' <文件>` 拿定位，再按行号定点读上述小节。

   **第 2 段·定点摘录（每部分 1 段）**：按骨架判断哪一节最代表性 → `grep -n '^```' <文件>` 找围栏行号 → 只读那 20–60 行加前面 1–2 行说明，逐字复制。

   **必须回读整节的三种情况**（不要为省字节写空泛的回顾）：① 骨架里那 3 行不足以说清这节做了什么；② 需要的关键数字不在 `continuity.fixed_numbers` 也不在检查点里；③ 摘录块与原文对不上（`part_lint.py --kind review` 会逐块校验「是否为原文连续子串」，报错就是回读信号）。

   **实测成本**（3 个部分的真实课程）：全文 182 KB → 骨架 27 KB（**15%**）+ 定点片段 ≈ 3.5 KB；复习操作总读取 **243,718 字节 → 约 92 KB（−62%）**。10 个部分的课程推算从 70 万字节降到约 15 万。两处旧省略继续有效：
   - **跳过已有的 `-review` 复习材料**：旧复习材料对新复习无用，只需从 `parts` 数组知道它们占用了哪些编号。
   - **`continuity.part_titles` 已有标题时直接用**，不必为取标题而打开文件。

   **兜底**：省读取靠的是协议 3b 的 `part_lint.py --kind review`——它把每个围栏块拿去和常规部分原文做子串比对，改写、拼接、漏标注都会报错。**没有跑这个检查，就不许用两段式读取**（宁可全读）。

2. **确定复习材料编号。** 术语固定：**常规部分** = `part-NN.md`，**复习部分** = `part-NN-review.md`，两者共用同一条编号轴。新复习部分的编号取 `parts` 里**所有部分（含复习部分）的最大编号 + 1**，零填充 2 位，文件名 `part-<NN>-review.md`。例如 `parts` 为 `["part-01.md", "part-02.md", "part-03.md"]` 时得到 `part-04-review.md`；**同名文件已存在时顺延下一个编号**（此前复习过 → `part-05-review.md`），不停止、不覆盖，并在结果里说明「这是第 k 份复习材料，旧的 `part-MM-review.md` 保留」。
   编号只用于文件名；复习材料 H1 里的「截至 part-NN」**只取最后的常规部分**，不含复习部分（见下方结构模板）。

3. **写入复习材料** `part-<NN>-review.md`，结构如下：

   ```
   # 复习：<教程标题>（截至 part-<最后的常规部分编号，忽略 -review>）

   [引子——1 到 2 段：点明这份材料的用途：久未接触后快速找回状态]

   ## 逐部分回顾
   每个常规部分一个小节（### part-NN — <该部分一级标题>）：
   该部分构建了什么、核心概念 2-3 个、关键数字/配置、一个代表性代码片段或命令（摘自原文，不新写）。

   ## 自测：间隔检索
   5-8 个问题，覆盖各部分的关键概念——要求读者先自己回答再对照正文。**出处写成「见 part-NN §k」**：`k` 取该章标题自带的编号（本类教程的标题多是 `1. xxx`、`0. xxx`），标题没有编号时写「见 part-NN §<标题前 6 字>」——**不要整条抄标题**（带反引号、冒号、括号的长标题会把题面撑爆）。不给答案。

   ## 重跑检查点
   列出各部分 `## 检查点` 的核心命令与预期输出（原样摘录），供读者在本地环境重新执行、确认手感仍在。

   ## 学习目标回顾（goal 缺失时本节仍保留，见下）
   对照 `goal` 说明当前已建立的能力，以及尚未覆盖的部分（如有）。**`goal` 缺失时不省掉本节**：开头写「本课未记录学习目标（`goal` 缺失，可在后续允许补齐 metadata 的写操作中补）」，然后按「已建立的能力 / 还没讲到的」照常写。若 `changed_interfaces` 非空，列出仍未闭合的接口变更；若 `open_threads` / 当前布局 research 归档有未决问题，列出 1-3 个最重要的。

   ## 还没讲到的（按 ID）
   直接按当前布局 canonical ledger 列出所有不是 `taught` / `duplicate` 的条目，**四个未讲状态组都要出现**（`queued` 欠着的 → `planned` 按池中行序还没轮到的 → `self-study` 用户选择自学的 → `dropped_by_user` 用户删去的），**某一组没有条目时写「无。」，不要整组省掉**。每条保留 ID，并按池中行序、承诺来源/位置与备注说明「为什么没讲 / 后续如何优先」；存在 `promise:` 或 legacy 等价承诺字段时，单独标一句「这是 Part X 留下的承诺」。末尾显示 `进度：taught / (taught + planned + queued)` 的数量与百分比，并按固定顺序列出 `planned`、`queued`、`taught`、`self-study`、`dropped_by_user`、`duplicate` 六态计数及合计。**全部已讲时写「无——所有列入清单的知识点都已讲完」**，但仍保留四组、进度与六态统计。这一段不从 metadata、research 或正文重建点级清单。

   ## 还可以继续深入的方向
   基于课程内容、`continuity.open_threads`、`next_hook`、canonical ledger 中的 `queued` / `planned` 条目以及当前布局 research 的非点级归档线索，给出 3-5 个延伸方向：
   每个方向一段话——是什么、为什么值得、从哪个部分的基础出发。
   末尾说明：想继续时调用 /lathe 续写 <slug>（可附带方向指导）。
   ```

   - 复习材料**不做新的网络研究**——内容全部来自已有部分。
   - **摘录的粒度与写法（0.6.0 明确）**：「原样摘录」= 从原文连续复制若干行，**保留原围栏首行与其类型标注**（`` ```rust runnable file=src/write.rs `` 照抄，不要简化成 `` ```rust ``——未标注的块会被下游按可执行代码处理），也保留原文的标点与注释；可以只取连续的一段，但**不得改写、不得拼接两个块、不得省略运行必需行**。`output` 与 `text` 块同样算「片段」，可以直接摘。写完后用脚本自查一次：每个围栏块的内容必须是某个部分原文的子串（`part_lint.py --kind review` 会报未标记的块）。
   - - **教学标注**：不用 `> [!PREDICT]` / `ASIDE` / `HEADS-UP`；`> [!RECALL]` 最多 1 个，**位置固定放在引子之后、「逐部分回顾」之前**，内容写成「先别往下读，凭记忆答三件事」的入口式提问（与「自测」小节形成入口/正题的关系，不重复出题）。

3b. **交付前检查（有 shell 时必做）。** 复习材料有自己的结构，教程结构检查对它不适用，所以用复习专用档位：

    python3 <SKILL_DIR>/scripts/part_lint.py <教程目录>/part-<NN>-review.md --kind review

它检查六个必备小节齐全与顺序、H1 格式（「截至 part-NN」必须是**常规部分**）、「逐部分回顾」是否覆盖全部常规部分、摘录代码块是否保留原文的类型标注、**每个围栏块是否为某个常规部分原文的连续子串（摘录保真）**，以及教学标注（PREDICT / ASIDE 应为 0，RECALL ≤1）；**不查验证状态横幅、检查点与练习**——复习材料永远不会被验证。**不跑** `ledger_check.py` 与 `trial_run.py`（复习不写账本、不产生新代码）。
结果写进本次播报的一行：**复习检查：** 六节 ✅ · 覆盖 N/N 个常规部分 ✅ · 摘录标注 ⚠️ k 处。

   - **接口变更要不要写「仍未闭合」**：`changed_interfaces` 里的条目满足「`supersedes` 为空 **且** 其后各部分的正文与当前布局 research 都没有回指/作废它」时，算**未闭合**，复习材料要列出；已经登记 `supersedes` 或已被后续部分改回的，算闭合，不列。此判据只在本文件内定义，复习**不需要**为此去读 `metadata.md`。

4. **只更新当前布局 metadata 的 Part 索引：**
   - 新布局写 `_lathe/metadata.json`，legacy 写根目录 `metadata.json`；不得在另一布局创建或写入 metadata。
   - 将复习材料文件名追加到 `parts` 数组，并在原协议支持 `part_versions` 时写入 `part_versions["part-<NN>-review.md"] = "<当前技能版本>"`；已有未知字段原样保留。
   - 除 `parts` / `part_versions` 外不更新其他 metadata 字段；尤其不修改 `status`、`continuity`、`model`、`lathe_version` 或任何点级镜像字段。复习不推进常规教学进度，也不重新开放已完结课程。

5. **告诉用户**复习材料已生成——文件路径、建议的使用方式（先自测再重跑检查点），以及两个后续选项：
   - 状态尚好、想继续精进 → `/lathe 续写 <slug>`；
   - 课程已完结且目标已达成、无需继续 → 保持现状即可。

## 边界

- 唯一写入是课程根目录的 `part-<NN>-review.md`，以及当前布局 metadata 的 `parts` / `part_versions`（原协议支持时）；不编辑已有部分，不写另一布局 metadata。
- canonical ledger 全程只读：新布局绝不写 `_lathe/knowledge-points.md`，legacy 绝不写 `syllabus.json`；尤其不改变任何知识点状态。research 也只读。
- 不引入新教学内容，不做网络研究，不修改 `status`、`tags`、`tools`、`sources`、`continuity` 或其他 metadata 字段。
- 复习材料计入 `parts` 但**不参与验证**（verify 跳过 `-review` 文件），**也不写验证状态横幅**（它永远不会被验证）；后续常规续写的编号在所有部分（常规 + 复习）的最大编号上递增。
